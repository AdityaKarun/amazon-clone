# Amazon Clone

An Amazon-inspired shopping web app built with HTML, CSS, and JavaScript while exploring JavaScript fundamentals through a hands-on project.

## Features

- Product listing and browsing
- Shopping cart functionality
- Checkout page
- Order history and tracking
- Interactive user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/downloads)
- A modern web browser
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)
- A local development server, such as the VS Code Live Server extension

### Installation and Setup

1. **Clone the repository**

   ```bash
   git clone <your-repository-url>
   ```

2. **Navigate to the project directory**

   ```bash
   cd amazon-clone
   ```

3. **Open the project in VS Code**

   ```bash
   code .
   ```

   Alternatively, open the project folder manually in your preferred code editor.

4. **Start a local development server**

   If you're using VS Code, install the Live Server extension if you haven't already. Open `amazon.html`, right-click inside the editor, and select **Open with Live Server**.

5. **Explore the application**

   The application should open in your browser. You can navigate between the shopping, checkout, orders, and tracking pages using the available links and controls.

   You can also access individual HTML pages directly through the local server URL, such as `/checkout.html` or `/orders.html`.

**Note:** Run the project through a local development server rather than opening the HTML files directly in your browser, as JavaScript features such as `fetch()` may require HTTP access.
